[K예술영재 프로젝트 통합 워크숍 아카이브 - 사용 안내]

파일 구성
- index.html : 방문자가 보는 공개 아카이브 사이트
- admin.html : 관리자 편집 페이지 (기본 비밀번호: karts2026)

운영 방법
1. admin.html 을 열고 비밀번호로 접속합니다.
2. 좌측 메뉴에서 기본정보 / 분야 / 메뉴 / 회차 / 공지·업데이트·자료를 편집합니다.
3. 상단 "임시저장" 버튼 → 같은 브라우저에서 index.html 을 열면 바로 미리보기 가능합니다.
   (다른 사람에게는 아직 보이지 않는 상태입니다)
4. "사이트 미리보기" 버튼으로 바로 새 탭에서 확인할 수 있습니다.
5. 확정되면 "내보내기(data.json)" 버튼으로 파일을 다운로드합니다.
6. 다운로드한 data.json 을 index.html, admin.html 과 같은 폴더(GitHub 저장소 등)에 업로드하면
   모든 방문자에게 반영됩니다.
7. admin.html 의 ADMIN_PASS 값(파일 내 JS 상수)을 원하는 비밀번호로 바꿔서 사용하세요.

주의
- GitHub Pages는 정적 호스팅이라 admin.html 에서 편집한 내용이 "자동으로" 실시간 반영되지는 않습니다.
  반드시 위 6번 단계(data.json 업로드)를 거쳐야 실제 방문자에게 보입니다.
- 실시간 자동 반영이 필요하면 Google Apps Script + 구글시트 백엔드로 업그레이드할 수 있습니다
  (기존 운영대시보드/주간업무 시스템과 동일한 방식). 필요하시면 이어서 작업 가능합니다.
